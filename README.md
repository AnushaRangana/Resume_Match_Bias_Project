# Resume Match & Bias Audit Project 📊

## Project Overview
This project demonstrates an AI/ML pipeline to score resumes for data-related jobs. It audits potential bias across job categories, mitigates length bias, and visualizes key skills using Python and SHAP explainability. The project focuses on building transparent and fair resume-screening logic using real-world datasets and beginner-friendly techniques.

## Key Features
* Bias Auditing: Analyzes scoring patterns to ensure fairness across job categories.
* Length Mitigation: Prevents longer resumes from receiving unfairly high scores.
* Explainable AI: Uses SHAP to visualize the features driving the model's decisions.

## How to Use
1. Open the FairHire_AI.ipynb file in this repository.
2. Click the "Open in Colab" button at the top of the notebook to run the code.
